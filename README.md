# Crime Pattern Analysis Using K-Means Clustering

## 1. Project Overview
An R-based data analytics and machine learning exercise focused on exploring crime patterns using K-Means Clustering. The analysis examines crime-related indicators, including Murder and Assault, to identify similarities and group observations into clusters.

## 2. Project Objective
- Explore crime-related data using statistical analysis.
- Apply K-Means clustering to identify patterns.
- Group observations based on similarities in crime indicators.
- Interpret cluster characteristics through data visualisation.

## 3. Dataset Description
The analysis uses the USArrests dataset, containing crime statistics across US states.

Key variables:
- Murder
- Assault
